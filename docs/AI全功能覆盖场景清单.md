## 五、智能辅助能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | 同名岗位检测 | 创建岗位时自动检查是否已有同名岗位，提示用户选择修改/新增班次/重新创建 |
| 2 | 高德地理编码 | 自动补全省市区信息并查询经纬度，用户只需说"兰溪市兰江街道兰荫路1号" |
| 3 | 搜索后自动填充ID | AI 先搜索岗位名称获取 ID，再调用其他函数，无需用户手动输入 ID |
| 4 | 日期智能推算 | 根据"明天""下周一"等自然语言推算真实日期 |
| 5 | 自然语言地址理解 | 支持"兰溪市兰江街道兰荫路1号"自由格式地址输入 |
| 6 | 语音输入 | 支持语音识别转文字输入（需麦克风权限） |
| 7 | 图片上传 | 支持上传图片识别内容创建岗位（当前模型不支持图片输入，功能预留） |

## 六、完整业务流程串联

```
用户 → "我要招保安，明天开始每天14-18点，时薪25，在兰溪市"
  │
  ├─ AI 提取信息，自然语言描述供确认
  │
  ├─ 用户确认
  │
  ├─ AI 调用 create_job_and_schedules
  │   ├─ _enrich_location 自动补全省市区和坐标
  │   └─ _check_job_duplicate 检查同名
  │
  ├─ 前端显示确认卡片
  │
  ├─ 用户点击确认创建
  │
  └─ /chat/execute → enterprise-service API → 创建成功

用户 → "看看谁报名了保安"
  │
  ├─ AI 调用 query_data(type=applications, jobTitle=保安)
  ├─ _execute_inline 执行查询
  ├─ AI 用自然语言总结返回
  └─ 用户看到报名列表

用户 → "通过张三的报名"
  │
  ├─ AI 确认意图
  ├─ 调用 execute_action(action=accept_application, targetId=xxx)
  ├─ 前端显示报名操作确认卡
  ├─ 用户确认
  └─ /chat/execute → 通过成功
```

## 七、AI 函数总览

| 函数名 | 类型 | 执行方式 | 说明 |
|--------|------|---------|------|
| `create_job_and_schedules` | 岗位创建 | 确认 → 后端 | 创建岗位含班次 |
| `update_job` | 岗位修改 | 确认 → 后端 | 修改岗位字段 |
| `add_schedule_to_job` | 班次新增 | 确认 → 后端 | 新增一个班次 |
| `update_schedule` | 班次修改 | 确认 → 后端 | 修改班次信息 |
| `copy_schedule` | 班次复制 | 确认 → 后端 | 复制到新日期 |
| `batch_create_schedules` | 批量班次 | 确认 → 后端 | 按日期范围+星期批量创建 |
| `search_jobs` | 搜索 | 内联执行 | 搜索岗位名称获取ID |
| `query_data` | 查询 | 内联执行 | 查岗位/班次/报名/考勤 |
| `execute_action` | 单条操作 | 确认 → 后端 | 14种子操作 |
| `batch_action` | 批量操作 | 确认 → 后端 | 2种子操作 |
