## 平台配置 - 内容运营 & 账号权限 & 客服中心

### Feature: 内容运营 - 轮播图管理

**Scenario: 查看轮播图列表**
```gherkin
Given 运营人员已登录平台
When 进入"平台配置 > 内容运营"页面，点击"轮播图"Tab
Then 显示轮播图列表，包含：
  | 字段 | 说明 |
  |------|------|
  | 图片预览 | 缩略图 |
  | 标题 | 轮播图标题 |
  | 跳转链接 | 点击跳转地址 |
  | 排序 | 显示顺序 |
  | 状态 | 启用/禁用 |
  | 创建时间 | 上传时间 |
  | 操作 | 编辑/删除/上移/下移 |
```

**Scenario: 新增轮播图**
```gherkin
Given 在轮播图管理页面
When 点击"新增轮播图"按钮
Then 弹出表单，填写：上传图片、标题、跳转链接、排序号、状态
  提交后新增轮播图，工人端首页显示
```

**Scenario: 编辑轮播图**
```gherkin
Given 在轮播图管理页面
When 点击某轮播图的"编辑"按钮
Then 可修改图片、标题、链接、排序、状态
  提交后更新轮播图
```

**Scenario: 调整轮播图顺序**
```gherkin
Given 在轮播图管理页面
When 点击某轮播图的"上移"或"下移"按钮
Then 该轮播图排序调整，前端显示顺序相应变化
```

### Feature: 服务费率配置

**Scenario: 查看服务费率配置**
```gherkin
Given 在平台配置页面
When 点击"服务费率"Tab
Then 显示当前服务费率配置：
  • 默认费率：全平台统一费率（如10%）
  • 分类费率：各职位分类可设置单独费率
  • 企业等级费率：不同等级企业可设置不同费率
  优先级：企业等级费率 > 分类费率 > 默认费率
```

**Scenario: 修改默认费率**
```gherkin
Given 在服务费率页面
When 编辑默认费率数值并保存
Then 新费率生效，所有未单独配置的职位使用新费率
```

**Scenario: 按分类设置费率**
```gherkin
Given 在服务费率页面
When 点击某分类的"编辑"按钮，输入该分类专属费率并保存
Then 该分类下的职位使用单独配置的费率
```

### Feature: 账号权限管理

**Scenario: 查看运营人员列表**
```gherkin
Given 超级管理员已登录平台
When 进入"平台配置 > 账号权限"页面
Then 显示运营人员列表，包含：
  | 字段 | 说明 |
  |------|------|
  | 账号 | 登录账号 |
  | 姓名 | 运营人员姓名 |
  | 角色 | 所属角色（超级管理员/运营主管/运营专员等） |
  | 手机号 | 联系方式 |
  | 状态 | 启用/禁用 |
  | 最后登录 | 最近登录时间 |
  | 创建时间 | 账号创建时间 |
  | 操作 | 编辑/重置密码/禁用/启用 |
```

**Scenario: 新增运营账号**
```gherkin
Given 在账号权限页面
When 点击"新增账号"按钮，填写账号、姓名、手机号、初始密码、选择角色
Then 新运营账号创建成功，可登录平台
```

**Scenario: 角色权限配置**
```gherkin
Given 在账号权限页面
When 点击"角色管理"Tab
Then 显示角色列表，可新增/编辑/删除角色
  编辑角色时可配置各模块的权限：查看/新增/编辑/删除/审核
```

### Feature: 工单处理

**Scenario: 查看工单列表**
```gherkin
Given 在客服中心页面
When 点击"工单处理"Tab
Then 显示工单列表，包含：
  • 工单ID、用户类型、用户名称、工单类型、状态、创建时间
  • 状态：待处理/处理中/已解决/已关闭
  • 操作：详情/处理
```

**Scenario: 处理工单**
```gherkin
Given 某工单状态为"待处理"
When 客服点击"处理"，查看工单详情和用户提交的凭证
Then 客服可：
  • 转处理中：标记开始处理
  • 回复用户：添加处理回复
  • 标记解决：问题解决后标记
  • 关闭工单：确认无需进一步处理
```
