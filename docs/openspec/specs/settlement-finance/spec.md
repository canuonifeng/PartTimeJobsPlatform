## 结算管理 & 交易财务

### Feature: 结算管理

**Scenario: 查看全平台结算单**
```gherkin
Given 运营人员已登录平台
When 进入"职位运营 > 结算管理"页面
Then 显示结算列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 结算单号 | 系统唯一单号 |
  | 工人姓名 | 结算工人 |
  | 手机号 | 联系方式 |
  | 企业名称 | 所属企业 |
  | 职位名称 | 所属职位 |
  | 班次日期 | 工作日期 |
  | 工时 | 实际工时 |
  | 结算金额 | 工人应得 |
  | 平台服务费 | 平台收入 |
  | 实际打款金额 | 实际打款 |
  | 状态 | 待结算/已结算/已撤销 |
  | 结算时间 | 完成时间 |
  | 操作 | 详情/撤销结算 |
```

**Scenario: 按状态筛选结算单**
```gherkin
Given 在结算管理页面
When 选择"待结算"状态并搜索
Then 列表只显示待结算的记录
```

**Scenario: 查看结算详情**
```gherkin
Given 在结算管理页面
When 点击某条记录的"详情"按钮
Then 显示结算详情弹窗，包含：
  • 工人信息：姓名、手机号、银行卡/微信账号
  • 企业信息：企业名称、联系人
  • 考勤信息：班次日期、签到时间、签退时间、工时
  • 费用明细：基本工资、补贴、扣款、总金额、服务费、实际打款
  • 结算记录：结算时间、操作人、打款凭证
```

**Scenario: 撤销已结算订单**
```gherkin
Given 某结算单状态为"已结算"且工人未提现
When 点击"撤销结算"并输入原因
Then 结算状态变为"已撤销"，资金退回企业账户，记录操作日志
```

**Scenario: 导出结算记录**
```gherkin
Given 在结算管理页面
When 点击"导出"按钮
Then 下载包含当前筛选条件的结算Excel文件
```

### Feature: 企业充值管理

**Scenario: 查看企业充值记录**
```gherkin
Given 运营人员已登录平台
When 进入"交易财务 > 企业充值"页面
Then 显示充值列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 充值单号 | 系统唯一编号 |
  | 企业名称 | 充值企业 |
  | 充值金额 | 金额 |
  | 支付方式 | 银行转账/微信/支付宝 |
  | 支付凭证 | 凭证图片 |
  | 状态 | 待审核/已到账/已拒绝 |
  | 提交时间 | 申请时间 |
  | 审核时间 | 处理时间 |
  | 操作 | 审核通过/审核拒绝 |
```

**Scenario: 审核充值申请 - 通过**
```gherkin
Given 某充值申请状态为"待审核"
When 运营人员核对凭证无误，点击"审核通过"
Then 充值状态变为"已到账"，企业余额增加，记录操作日志
```

**Scenario: 审核充值申请 - 拒绝**
```gherkin
Given 某充值申请状态为"待审核"
When 运营人员发现凭证有问题，点击"审核拒绝"并输入原因
Then 充值状态变为"已拒绝"，通知企业
```

### Feature: 财务对账

**Scenario: 查看每日对账报表**
```gherkin
Given 运营人员已登录平台
When 进入"交易财务 > 财务对账"页面
Then 显示对账日历或列表，包含每日对账概览：
  | 字段 | 说明 |
  |------|------|
  | 日期 | 对账日期 |
  | 企业充值总额 | 当日企业充值总和 |
  | 工人提现总额 | 当日工人提现总和 |
  | 平台服务费收入 | 当日服务费总和 |
  | 结算总金额 | 当日结算总和 |
  | 对账状态 | 已对账/待对账 |
  | 操作 | 查看详情/导出 |
```

**Scenario: 查看某日对账详情**
```gherkin
Given 在财务对账页面
When 点击某日的"详情"按钮
Then 显示该日对账详情，包含：
  • 资金汇总：充值总额、提现总额、服务费总额、结算总额
  • 充值明细：所有企业充值记录列表
  • 提现明细：所有工人提现记录列表
  • 结算明细：所有结算单列表
  • 服务费明细：每笔结算的服务费明细
```

**Scenario: 导出对账报表**
```gherkin
Given 在财务对账页面
When 选择日期范围并点击"导出对账报表"
Then 下载该日期范围内的财务对账Excel文件
```

**Scenario: 平台服务费统计**
```gherkin
Given 在财务对账页面
When 点击"服务费统计"Tab
Then 显示平台服务费统计图表：
  • 按日期：每日/每周/每月服务费趋势图
  • 按企业：各企业服务费贡献排行
  • 按职位分类：各分类服务费占比
```
