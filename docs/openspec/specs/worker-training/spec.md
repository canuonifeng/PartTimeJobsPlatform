# Worker Training 规格（v2）

## 需求

### REQ-WT-1: 课程包含按序排列的多类型课时
**优先级**: P0

**描述**: 一门课程包含多个课时，课时类型为视频（VIDEO）、音频（AUDIO）、文档（DOCUMENT）、图文（IMAGE_TEXT）、考试（EXAM）。课时有固定顺序，后置课时须在前置课时完成后才可开始。

**场景**:
- 平台为课程配置 3 个课时（视频、文档、考试），排序 1/2/3
- 兼职打开课程详情 → 按序展示课时，课时 2/3 显示锁定状态
- 兼职完成课时 1 → 课时 2 解锁可开始
- 兼职尝试在课时 1 未完成时开始课时 2 → 系统拒绝

**约束**:
- 课时类型枚举：VIDEO/AUDIO/DOCUMENT/IMAGE_TEXT/EXAM
- 课程发布后，课时顺序变更仍生效

**验收标准**:
- [ ] 课程详情按序返回课时列表及每个课时的完成状态与锁定状态
- [ ] 未完成前置课时时，开始后置课时被拒绝

### REQ-WT-2: 学习型课时完成判定
**优先级**: P0

**描述**: 视频/音频课时须观看进度达到 100% 才标记完成；文档/图文课时标记"已读"即完成。

**场景**:
- 兼职开始视频课时，观看进度上报 60% → 课时状态 IN_PROGRESS，进度 60
- 兼职上报进度 100% → 课时标记 COMPLETED
- 兼职打开文档课时并点击"已完成阅读" → 课时标记 COMPLETED

**约束**:
- 进度上报只允许单调递增（不回退）
- 视频/音频课时未达 100% 不得标记完成

**验收标准**:
- [ ] 视频/音频课时进度达 100% 自动完成
- [ ] 文档/图文课时标记已读即完成

### REQ-WT-3: 考试课时从题库随机抽题
**优先级**: P0

**描述**: 考试课时引用一个题库，并按配置规则（时长、题型、各题型题量、每题分值、及格分）在开考时从题库的已发布题目中随机抽取试卷；返回给兼职的试卷不含答案。

**场景**:
- 考试课时配置：题库 A、时长 30 分钟、单选 10 题×2 分、判断 5 题×1 分、及格 60 分，总分自动汇总为 25 分→ 注：此处配置示例总分 25，及格分应 ≤ 总分；平台配置时可提示
- 兼职开始考试 → 系统从题库 A 的已发布题目中随机抽单选 10 道、判断 5 道生成试卷
- 兼职看到的试卷不包含正确答案字段

**约束**:
- 抽题范围为题库内 status=PUBLISHED 的题目
- 若某题型已发布题量不足配置数量，禁止开始考试并提示平台重新配置
- 总分 = Σ(题型题量 × 每题分值)，自动汇总展示

**验收标准**:
- [ ] 开考时按规则随机抽题且不含答案
- [ ] 题量不足时拒绝开考并提示

### REQ-WT-4: 考试判分、重考与试卷快照
**优先级**: P0

**描述**: 兼职提交答案后按各题型每题分值判分；得分 ≥ 及格分则该考试课时完成，并记录整份试卷快照；得分不足可重考（不限次数）。

**场景**:
- 兼职提交试卷，判分得 70 分（及格 60）→ 课时 COMPLETED，记录快照（题目+我的答案+正确答案+得分）
- 兼职提交试卷，判分得 50 分 → 课时 FAILED，可再次进入考试
- 兼职重考并得分 80 → 课时 COMPLETED，快照更新为最新一次通过记录

**约束**:
- 单选/判断：答案完全一致得分，否则 0 分
- 多选：所选选项与正确答案完全一致才得分（严格全对），否则 0 分
- 已通过（COMPLETED）的考试课时可重复查看快照，但不强制重考

**验收标准**:
- [ ] 判分按每题分值正确累计
- [ ] 不及格允许重考，通过后记录/更新试卷快照

### REQ-WT-5: 课程完成自动发放认证
**优先级**: P0

**描述**: 课程的**全部课时完成**（考试课时须通过）后，课程视为完成，系统自动为该兼职发放课程关联的技能认证（ACTIVE，含有效期）。

**场景**:
- 兼职完成课程全部课时 → 系统发放该课程 certification_id 对应的认证，expires_at 按认证 valid_days 计算
- 兼职已持有该认证（ACTIVE 未过期）→ 不重复发放
- 认证定义已 DISABLED → 不发放并记录异常

**约束**:
- 课程完成判定：所有课时 status=COMPLETED
- 认证发放幂等：已有有效认证不重复发放

**验收标准**:
- [ ] 全部课时完成时自动发放认证（仅一次）
- [ ] 已有有效认证时不重复发放

### REQ-WT-6: 我的认证与抢单拦截（保持）
**优先级**: P0

**描述**: 兼职可查看自己持有的认证及有效期；标注任务抢单仍按 task_type 校验 ACTIVE 认证，未认证被拦截并引导培训。

**场景**:
- 兼职进入"我的认证"→ 展示认证名称、获得时间、有效期/永久
- 兼职持有 ANNOTATION 对应 ACTIVE 认证 → 可正常抢单
- 兼职未持有或认证过期/停用 → 抢单被拒，提示去培训

**约束**:
- 认证校验逻辑与 v1 一致，仅认证来源改为新发放链路

**验收标准**:
- [ ] 我的认证列表正确展示
- [ ] 抢单拦截行为与 v1 保持一致
