## 风控治理 - 投诉工单 & 风控中心 & 评价管理

### Feature: 投诉工单

**Scenario: 查看投诉列表**
```gherkin
Given 运营人员已登录平台
When 进入"风控治理 > 投诉工单"页面
Then 显示投诉列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 工单ID | 系统唯一编号 |
  | 投诉类型 | 企业投诉工人/工人投诉企业 |
  | 投诉人 | 投诉方名称 |
  | 被投诉方 | 被投诉方名称 |
  | 关联职位 | 相关职位（如有） |
  | 关联班次 | 相关班次（如有） |
  | 投诉原因 | 投诉原因分类 |
  | 状态 | 待处理/处理中/已解决/已关闭 |
  | 优先级 | 高/中/低 |
  | 提交时间 | 投诉时间 |
  | 操作 | 详情/处理 |
```

**Scenario: 按状态筛选投诉**
```gherkin
Given 在投诉工单页面
When 选择"待处理"状态并搜索
Then 列表只显示待处理的投诉工单
```

**Scenario: 查看投诉详情**
```gherkin
Given 在投诉工单页面
When 点击某工单的"详情"按钮
Then 显示投诉详情页，包含：
  • 投诉基本信息：投诉类型、投诉人、被投诉人、提交时间
  • 投诉内容：投诉描述、图片/视频凭证
  • 关联信息：职位信息、班次信息、考勤记录
  • 沟通记录：双方沟通历史、平台处理记录
  • 处理操作：转处理中、仲裁、标记解决、关闭
```

**Scenario: 处理投诉 - 标记处理中**
```gherkin
Given 某投诉状态为"待处理"
When 运营人员点击"开始处理"
Then 工单状态变为"处理中"，记录处理人
```

**Scenario: 处理投诉 - 平台仲裁**
```gherkin
Given 某投诉状态为"处理中"
When 运营人员核实双方举证后，点击"仲裁处理"
Then 选择仲裁结果（支持投诉方/支持被投诉方/双方各半）
  输入处理说明，确认后工单状态变为"已解决"
  通知双方仲裁结果，如有处罚则执行相应处罚
```

**Scenario: 关闭投诉工单**
```gherkin
Given 某投诉已妥善处理
When 运营人员点击"关闭工单"并输入关闭说明
Then 工单状态变为"已关闭"，记录关闭时间和说明
```

### Feature: 风控中心

**Scenario: 查看异常行为监控**
```gherkin
Given 运营人员已登录平台
When 进入"风控治理 > 风控中心"页面
Then 显示异常行为监控面板，包含：
  • 今日异常事件数统计
  • 异常类型分布图表（频繁取消/异常打卡/恶意投诉等）
  • 高风险用户列表
  • 最新异常事件列表
```

**Scenario: 查看黑名单列表**
```gherkin
Given 在风控中心页面
When 点击"黑名单"Tab
Then 显示黑名单列表，包含：
  | 字段 | 说明 |
  |------|------|
  | 用户ID | 系统唯一ID |
  | 用户类型 | 企业/工人 |
  | 用户名称 | 名称 |
  | 拉黑原因 | 违规原因 |
  | 拉黑时间 | 操作时间 |
  | 操作人 | 执行拉黑的运营 |
  | 到期时间 | 永久/具体日期 |
  | 操作 | 解除拉黑 |
```

**Scenario: 加入黑名单**
```gherkin
Given 某用户存在严重违规行为
When 在用户详情页或黑名单页面点击"加入黑名单"
Then 输入拉黑原因、选择拉黑期限（永久/7天/30天）
  确认后用户加入黑名单，限制相应功能
  通知用户被拉黑及原因
```

**Scenario: 解除黑名单**
```gherkin
Given 某用户在黑名单中
When 点击"解除拉黑"并输入说明
Then 用户从黑名单移除，恢复正常功能
```

**Scenario: 查看白名单列表**
```gherkin
Given 在风控中心页面
When 点击"白名单"Tab
Then 显示白名单列表，包含：
  • 用户信息、加入原因、加入时间、操作人
  • 白名单用户可跳过部分风控检查
```

**Scenario: 风控规则配置**
```gherkin
Given 在风控中心页面
When 点击"规则配置"Tab
Then 显示可配置的风控规则：
  • 频繁取消报名：X小时内取消Y次 → 限制报名Z小时
  • 异常打卡：连续X天定位偏差超Y米 → 标记异常
  • 恶意投诉：X天内Y次投诉不成立 → 限制投诉
  运营人员可调整各规则的阈值
```

### Feature: 评价管理

**Scenario: 查看评价列表**
```gherkin
Given 运营人员已登录平台
When 进入"风控治理 > 评价管理"页面
Then 显示评价列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 评价ID | 系统唯一ID |
  | 评价类型 | 企业评工人/工人评企业 |
  | 评价方 | 评价人名称 |
  | 被评价方 | 被评价人名称 |
  | 关联职位 | 相关职位 |
  | 评分 | 1-5星 |
  | 评价内容 | 文字评价 |
  | 是否违规 | 是/否 |
  | 评价时间 | 提交时间 |
  | 操作 | 详情/删除违规 |
```

**Scenario: 按违规状态筛选**
```gherkin
Given 在评价管理页面
When 选择"违规"状态并搜索
Then 列表只显示标记为违规的评价
```

**Scenario: 删除违规评价**
```gherkin
Given 某评价包含违规内容
When 点击"删除违规"并输入原因
Then 该评价被删除，对被评价方的影响撤销
  通知评价方评价被删除及原因
```

**Scenario: 信用分体系**
```gherkin
Given 在用户详情页
When 查看"信用分"Tab
Then 显示用户信用分详情：
  • 当前信用分（满分100）
  • 信用等级：优秀(90+)/良好(75-89)/合格(60-74)/较差(<60)
  • 加分记录：完成工作、获得好评
  • 扣分记录：违规行为、投诉成立、差评
  运营人员可手动调整信用分并备注原因
```

**Scenario: 查看企业信用详情**
```gherkin
Given 在企业详情页
When 点击"信用信息"Tab
Then 显示：
  • 综合评分、评价数量
  • 各维度评分：准时发薪、工作环境、管理规范
  • 最近评价列表
  • 违规记录
```

**Scenario: 查看工人信用详情**
```gherkin
Given 在工人详情页
When 点击"信用信息"Tab
Then 显示：
  • 综合评分、完成工作数
  • 各维度评分：准时到岗、工作态度、服从管理
  • 最近评价列表
  • 违规记录
```
