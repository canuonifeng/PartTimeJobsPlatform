## 报名审核（平台视角）

### Feature: 报名列表

**Scenario: 查看全平台报名记录**
```gherkin
Given 运营人员已登录平台
When 进入"职位运营 > 报名审核"页面
Then 显示报名列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 报名ID | 系统唯一ID |
  | 职位名称 | 报名的职位 |
  | 企业名称 | 所属企业 |
  | 工人姓名 | 报名工人 |
  | 工人手机号 | 联系方式 |
  | 班次日期 | 报名的班次 |
  | 状态 | 待审核/已通过/已拒绝/已取消 |
  | 报名时间 | 提交时间 |
  | 审核时间 | 最后操作时间 |
  | 操作 | 详情/通过/拒绝 |
```

**Scenario: 按状态筛选**
```gherkin
Given 在报名审核页面
When 选择"待审核"状态并搜索
Then 列表只显示待审核的报名记录
```

**Scenario: 按时间范围筛选**
```gherkin
Given 在报名审核页面
When 选择开始日期和结束日期并搜索
Then 列表只显示该时间段内的报名记录
```

**Scenario: 按企业/工人搜索**
```gherkin
Given 在报名审核页面
When 输入企业名称或工人姓名/手机号并搜索
Then 列表只显示匹配的报名记录
```

### Feature: 报名审核

**Scenario: 审核通过报名**
```gherkin
Given 有状态为"待审核"的报名记录
When 点击"通过"按钮并确认
Then 该报名状态变为"已通过"，通知工人和企业
```

**Scenario: 审核拒绝报名**
```gherkin
Given 有状态为"待审核"的报名记录
When 点击"拒绝"按钮，输入拒绝原因并确认
Then 该报名状态变为"已拒绝"，记录拒绝原因，通知工人
```

**Scenario: 查看报名详情**
```gherkin
Given 在报名审核页面
When 点击某条记录的"详情"按钮
Then 显示报名详情弹窗，包含：
  • 工人信息：姓名、手机号、头像、性别、年龄
  • 职位信息：职位名称、企业名称、薪资、地点
  • 班次信息：班次日期、时间、地点
  • 报名信息：报名时间、状态、审核记录
```

### Feature: 批量操作

**Scenario: 批量通过报名**
```gherkin
Given 在报名审核页面
When 勾选多个"待审核"的报名记录并点击"批量通过"
Then 弹出确认对话框，确认后所选报名全部变为"已通过"
```

**Scenario: 批量拒绝报名**
```gherkin
Given 在报名审核页面
When 勾选多个"待审核"的报名记录并点击"批量拒绝"
Then 弹出对话框输入统一拒绝原因，确认后所选报名全部变为"已拒绝"
```

**Scenario: 导出报名记录**
```gherkin
Given 在报名审核页面
When 点击"导出"按钮
Then 下载包含当前筛选条件的报名Excel文件
```

### Feature: 异常报名处理

**Scenario: 标记异常报名**
```gherkin
Given 发现某条报名存在异常（如重复报名、信息造假）
When 点击"标记异常"并输入原因
Then 该报名标记为"异常"状态，工人进入风控观察名单
```

**Scenario: 取消已通过的报名**
```gherkin
Given 某报名状态为"已通过"但工人无法上岗
When 点击"取消报名"并输入原因
Then 该报名状态变为"已取消"，释放班次名额，通知双方
```
