## 数据运营 - 报表中心 & 活动运营

### Feature: 报表中心

**Scenario: 运营概览报表**
```gherkin
Given 运营人员已登录平台
When 进入"数据运营 > 报表中心"页面
Then 显示运营概览看板，包含核心指标：
  • 今日/本周/本月数据：
    - 新增职位数
    - 新增报名数
    - 完成考勤数
    - 结算总金额
    - 平台服务费收入
    - 新增企业数
    - 新增工人数
  • 核心指标趋势图（折线图：近7天/30天）
```

**Scenario: 企业活跃度分析**
```gherkin
Given 在报表中心页面
When 点击"企业分析"Tab
Then 显示企业活跃度分析报表：
  • 企业活跃度排行：按发布职位数、报名数、结算金额排序
  • 企业活跃度分布：活跃/沉默/流失企业数量分布饼图
  • 企业增长趋势：每日新增企业数折线图
  • 企业列表：包含活跃度标签、最近活跃时间、累计贡献
```

**Scenario: 工人活跃度分析**
```gherkin
Given 在报表中心页面
When 点击"工人分析"Tab
Then 显示工人活跃度分析报表：
  • 工人活跃度排行：按报名数、完成工作数、收入排序
  • 工人活跃度分布：活跃/沉默/流失工人数量分布饼图
  • 工人增长趋势：每日新增工人数折线图
  • 工人留存率：次日/7日/30日留存率
```

**Scenario: 职位供需分析**
```gherkin
Given 在报表中心页面
When 点击"供需分析"Tab
Then 显示职位供需分析报表：
  • 按分类：各职位分类的招聘数 vs 报名数对比
  • 按地区：各城市的招聘数 vs 报名数对比
  • 供需缺口：招聘缺口较大的分类/地区排行
  • 职位招聘完成率：各职位分类的平均招满时长
```

**Scenario: 转化漏斗分析**
```gherkin
Given 在报表中心页面
When 点击"转化漏斗"Tab
Then 显示转化漏斗图表：
  • 职位浏览数 → 点击报名数 → 审核通过数 → 实际到岗数 → 完成结算数
  • 每一步的转化率和流失率
  • 可按时间范围筛选查看
```

**Scenario: 导出报表**
```gherkin
Given 在任意报表Tab
When 点击"导出报表"按钮
Then 下载当前查看的报表Excel文件
```

### Feature: 活动运营

**Scenario: 新人红包配置**
```gherkin
Given 运营人员已登录平台
When 进入"数据运营 > 活动运营"页面，点击"新人红包"Tab
Then 显示新人红包配置表单：
  • 红包金额：首单完成后奖励金额
  • 有效期限：注册后X天内完成首单
  • 最低工时要求：完成至少X小时工作
  • 活动开始/结束时间
  运营人员可配置参数并启用/禁用活动
```

**Scenario: 满单奖励配置**
```gherkin
Given 在活动运营页面
When 点击"满单奖励"Tab
Then 显示满单奖励配置表单：
  • X天内完成Y单 → 奖励Z元
  • 可配置多档奖励（如7天3单、7天5单、30天10单）
  • 活动开始/结束时间
  运营人员可新增/编辑/删除各档奖励
```

**Scenario: 限时置顶活动**
```gherkin
Given 在活动运营页面
When 点击"限时置顶"Tab
Then 显示限时置顶活动配置：
  • 活动名称
  • 活动时间：开始/结束时间
  • 参与条件：企业等级/充值金额等
  • 置顶时长：赠送X天置顶
  • 置顶职位数限制：每个企业最多Y个职位
  运营人员可创建新活动或管理已有活动
```

**Scenario: 节日活动配置**
```gherkin
Given 在活动运营页面
When 点击"节日活动"Tab
Then 显示节日活动配置表单：
  • 活动名称（如"五一劳动节双倍积分"）
  • 活动时间
  • 活动类型：服务费折扣/额外奖励/积分翻倍
  • 活动规则：具体奖励或折扣规则
  • 活动说明文案
  运营人员可配置并启用/禁用节日活动
```

**Scenario: Push推送管理**
```gherkin
Given 在活动运营页面
When 点击"Push推送"Tab
Then 显示推送管理界面：
  • 新建推送：填写标题、内容、选择推送人群（全部/特定地区/特定分类/活跃用户）
  • 推送历史：已发送的推送列表（标题、发送时间、送达数、点击数）
  • 定时推送：设置定时发送时间
  • 推送模板：常用推送模板快速选择
```

**Scenario: 活动效果统计**
```gherkin
Given 在活动运营页面
When 点击某活动的"效果统计"
Then 显示该活动的效果数据：
  • 参与人数/企业数
  • 活动带来的职位数/报名数增量
  • 活动投入成本
  • 活动ROI（投资回报率）
  • 活动前后对比数据
```
