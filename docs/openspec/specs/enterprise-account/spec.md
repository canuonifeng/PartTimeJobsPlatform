## 新增需求

### 需求：企业可以注册账号
系统须允许企业注册，填写企业名称、营业执照、联系信息和管理员账号。

#### 场景：提交注册申请
- **当** 企业用户填写注册表单并提交
- **则** 系统须创建状态为"待审核"的企业账号

#### 场景：注册审核通过
- **当** 平台运营人员通过企业注册审核
- **则** 系统须激活企业账号并通知企业管理员

#### 场景：注册时由运营平台设置后缀
- **当** 平台运营人员创建企业时设置账号后缀
- **则** 系统须将后缀存储到 `enterprises.email_suffix` 字段
- **且** 系统须校验后缀唯一性

### 需求：企业管理员可管理团队成员
系统须允许企业管理员邀请和管理团队成员，并分配角色权限。

#### 场景：邀请团队成员
- **当** 企业管理员向新成员发送带有角色分配的邀请
- **则** 系统须创建待处理的邀请并发送通知

#### 场景：成员接受邀请
- **当** 被邀请用户接受邀请
- **则** 系统须激活该成员并赋予对应角色权限

#### 场景：邀请时使用后缀格式
- **当** 企业已配置账号后缀
- **则** 系统须在邀请成员时使用 `{前缀}@{后缀}` 格式显示账号

### 需求：企业支持基于角色的权限控制
系统须按角色权限控制功能访问，设管理员、HR、主管、财务四个角色。

#### 场景：HR发布岗位
- **当** 拥有HR角色的用户访问岗位创建页面
- **则** 系统须允许其创建和发布岗位

#### 场景：财务访问薪资模块
- **当** 拥有财务角色的用户访问薪资模块
- **则** 系统须允许其查看和处理薪资

#### 场景：主管管理排班
- **当** 拥有主管角色的用户访问排班模块
- **则** 系统须允许其管理排班和考勤

### 需求：企业可管理资质文件
系统须允许企业上传和更新资质文件（营业执照、相关认证）。

#### 场景：更新资质文件
- **当** 企业管理员上传新的资质文件
- **则** 系统须存储文件并更新企业的资质状态
