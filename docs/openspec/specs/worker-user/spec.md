## 新增需求

### 需求：兼职可通过微信注册和登录
系统须允许兼职通过微信授权（小程序）进行注册和登录。

#### 场景：首次微信登录
- **当** 兼职首次打开小程序并授权微信登录
- **则** 系统须创建关联微信 Open ID 的兼职账号

#### 场景：再次微信登录
- **当** 再次打开小程序
- **则** 系统须通过微信会话自动登录

### 需求：兼职可完善个人资料
系统须要求兼职在首次登录后完善资料（姓名、手机号、头像）才能使用找活功能。

#### 场景：填写必填资料
- **当** 兼职提交姓名、手机号和头像
- **则** 系统须保存资料并开放找活功能

### 需求：兼职可浏览和搜索岗位
系统须允许兼职浏览已发布的岗位列表，并支持按关键词、分类、位置和薪资筛选。

#### 场景：浏览岗位列表
- **当** 兼职打开岗位列表页
- **则** 系统须按发布时间倒序展示已发布岗位

#### 场景：按分类筛选岗位
- **当** 兼职选择岗位分类筛选条件
- **则** 系统须仅展示该分类下的岗位

### 需求：兼职可报名岗位
系统须允许兼职查看岗位详情并提交报名申请。

#### 场景：查看详情并报名
- **当** 兼职打开岗位详情页并点击"报名"
- **则** 系统须创建状态为"待处理"的报名记录

### 需求：兼职可查看排班和打卡
系统须提供排班视图和打卡签到/签退功能。

#### 场景：查看即将到来的排班
- **当** 兼职打开排班页面
- **则** 系统须按日期分组展示即将到来的排班

#### 场景：签到
- **当** 兼职在有效时间窗口和位置范围内打卡签到
- **则** 系统须记录签到时间并更新考勤状态

### 需求：兼职可查看收入并提现
系统须允许兼职查看收入明细并将可用余额提现。

#### 场景：查看收入汇总
- **当** 兼职打开收入页面
- **则** 系统须展示总收入、待结算金额、可用余额和提现记录

#### 场景：提现到微信
- **当** 兼职申请提现到微信支付
- **则** 系统须处理提现并更新余额
