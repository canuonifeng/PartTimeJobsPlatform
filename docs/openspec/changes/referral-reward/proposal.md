## Why

平台需要用户增长机制，通过邀请奖励激励老用户邀请新用户注册。老用户分享专属链接或海报，新用户注册后在规定时间内完成打工任务，平台自动发放奖励给邀请人。时间和奖励金额由运营后台配置，灵活调整运营策略。

## What Changes

- 新增邀请链接生成：每个用户生成唯一邀请链接
- 新增邀请海报生成：用户可生成带二维码的邀请海报
- 新增邀请关系记录：新用户通过链接/海报注册时自动绑定邀请关系
- 新增奖励规则配置：运营后台可配置奖励时间和金额
- 新增奖励发放逻辑：被邀请人在规定时间内完成打工后，自动发放奖励给邀请人
- 新增邀请记录查询：用户可查看被邀请人列表、出勤状态、奖励状态
- 新增收入明细展示：收入页展示邀请奖励记录

## Capabilities

### New Capabilities

- `referral-link`: 邀请链接和海报生成，包括唯一链接、二维码海报
- `referral-binding`: 邀请关系绑定，新用户通过链接/海报注册时自动建立邀请关系
- `referral-reward`: 邀请奖励发放，满足条件后自动发放现金奖励
- `referral-stats`: 邀请统计查询，用户查看被邀请人列表、出勤状态、奖励状态
- `referral-config`: 奖励规则配置，运营后台可配置时间和金额

## Impact

- **数据库**：新增 `referral_code`、`referral_record`、`referral_reward`、`referral_config` 表
- **后端 API**：
  - c-service：新增邀请链接/海报生成、邀请绑定、被邀请人列表、奖励查询接口
  - enterprise-service：新增奖励规则配置接口
- **前端页面**：
  - worker-uniapp：新增邀请页面、邀请记录页面、收入页展示奖励
  - enterprise-pc：新增奖励规则配置页面
- **依赖**：需引入二维码生成库（如 ZXing 或 Hutool）
