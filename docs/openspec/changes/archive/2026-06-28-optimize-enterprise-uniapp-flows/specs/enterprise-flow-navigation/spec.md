## ADDED Requirements

### Requirement: 企业端展示 5 步业务流进度引导
系统须在企业端小程序首页和招聘流程页展示业务流进度组件，清晰引导用户完成"创建岗位 → 创建班次 → 审核报名 → 考勤确认 → 薪资结算"的完整流程。

#### Scenario: 首页展示业务流卡片
- **WHEN** 企业用户打开首页
- **THEN** 系统在工作台区域展示 5 步业务流进度卡片，当前有代办操作的步骤高亮显示，已完成步骤显示对勾标记

#### Scenario: 步骤点击跳转
- **WHEN** 企业用户点击业务流中的某个步骤
- **THEN** 系统跳转到该步骤对应的操作页面

#### Scenario: 招聘流程页展示业务流列表
- **WHEN** 企业用户切换到招聘流程 Tab
- **THEN** 系统以列表形式展示 5 步流程，每步显示待处理数量、可操作的快捷入口

#### Scenario: 步骤状态同步
- **WHEN** 企业用户在某个步骤完成操作（如发布岗位）
- **THEN** 系统自动更新业务流组件的步骤状态，引导用户进入下一步
