# Question Bank Management 规格

## 需求

### REQ-QB-1: 题库管理
**优先级**: P0

**描述**: 平台可创建、编辑、停用/启用题库；题库全局共享，可被多个考试课时引用。

**场景**:
- 平台创建题库"标注规范题库"（名称、描述）→ 状态 ACTIVE
- 平台编辑题库名称/描述
- 平台停用题库 → 状态 DISABLED，引用它的考试课时在开考时被拒绝并提示配置无效
- 平台重新启用题库 → 状态 ACTIVE

**约束**:
- 题库名称唯一
- 停用题库不影响已存在的试卷快照

**验收标准**:
- [ ] 题库增删改查与启停可用，名称唯一校验生效
- [ ] 引用已停用题库的考试课时无法开考

### REQ-QB-2: 题目管理
**优先级**: P0

**描述**: 平台在题库下维护题目，题目类型为单选（SINGLE_CHOICE）、多选（MULTIPLE_CHOICE）、判断（JUDGE）；题目可编辑、删除与发布/下线。

**场景**:
- 平台在题库 A 下创建单选题目（题干、选项、正确答案、解析）→ 状态 DRAFT
- 平台编辑题目选项与答案
- 平台发布题目 → 状态 PUBLISHED，可被考试抽题
- 平台下线题目 → 状态 OFFLINE，不再被抽题（已抽出的试卷不受影响）
- 平台删除 DRAFT 题目 → 记录删除

**约束**:
- 单选/判断必须且只能有一个正确答案；多选至少两个正确选项
- 选项与答案以 JSON 存储
- 删除仅限 DRAFT 状态题目；已发布题目先下线再删

**验收标准**:
- [ ] 三种题型均可增删改查
- [ ] 发布状态（DRAFT/PUBLISHED/OFFLINE）流转正确
- [ ] 已发布题目可被考试随机抽中，下线后不再被抽中

### REQ-QB-3: 题目数据校验
**优先级**: P1

**描述**: 创建/编辑题目时校验题型枚举、选项数量、答案合法性。

**场景**:
- 平台创建单选题目但未填选项 → 拒绝并提示
- 平台创建多选题目只填 1 个正确选项 → 拒绝并提示
- 平台创建判断题目答案非"对/错" → 拒绝并提示

**约束**:
- 单选/多选选项数 2~6；判断题答案固定 TRUE/FALSE

**验收标准**:
- [ ] 非法题目数据被拒绝并给出明确提示
