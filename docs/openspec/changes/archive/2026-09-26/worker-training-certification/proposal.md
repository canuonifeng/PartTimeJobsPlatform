# Proposal: worker-training-certification（模型升级 v2）

## 背景与问题

当前培训模块（v1，已上线）的模型为"课程 = 内容 + 考试"：`training_courses` 直接存 `content`（课程正文）、`exam_json`（题目）、`pass_score`（及格分）。该模型存在以下问题：

1. **课程粒度粗**：一门课只有一段正文 + 一次考试，无法承载"视频/音频/文档/图文 + 考试"混合的多课时教学结构。
2. **题目复用性差**：考试题目内嵌在课程里，同一批题无法被多个课程复用，维护成本高。
3. **考试规则僵硬**：不能配置考试时长、按题型抽题、题型题量与分值，无法满足不同认证的差异化考核要求。
4. **进度无法细粒度记录**：学习记录只到课程级，无法记录"看完视频/读完文档"等课时级进度，也无法留存试卷快照。

## 变更目标

将培训模块升级为"**课程 → 多课时（视频/音频/文档/图文/考试）→ 题库/考试规则**"模型：

1. 课程包含多个**课时**，课时类型：视频、音频、文档、图文、考试。
2. 新增**题库模块**：题库全局共享，题目在平台端做增删改查与发布管理。
3. **考试课时**引用题库并配置规则（考试时长、考哪些题型、各题型题量、每题分值、及格分）；总分由规则自动汇总；考试时从题库随机抽题。
4. 课时有**顺序要求**；视频/音频需看完、文档/图文已读即完成；**课程完成 = 全部课时完成且考试课时通过**，完成时发放认证。
5. 考试允许**重考**；考试通过后记录**试卷快照**留档。
6. 废弃 v1 的 `content/exam_json/pass_score` 字段与旧学习记录模型；旧认证与学习记录不迁移兼容。

## 范围

- **包含**：
  - 平台端：题库管理、题目管理（含发布）、课时管理（含考试课时规则配置）、课程管理调整
  - C端：课时级学习流程（视频/音频进度、文档/图文已读、考试抽题/判分/重考）、课程完成触发认证发放
  - 数据库：新表 + 字段废弃迁移脚本
  - 抢单拦截（annotation-grab-gate）保持现有逻辑不变，仅确保新认证发放链路与之兼容
- **不包含（非目标）**：
  - 视频/音频的流媒体上传、转码、播放器 SDK（仅存 URL 与时长，前端自行播放）
  - 人工阅卷题型（简答/填空）；题型仅限单选/多选/判断
  - 多选部分得分（多选按"全对得分"计）
  - 旧数据（v1 课程内容、学习记录、已发放认证）的迁移或兼容

## 验收标准

- [ ] 平台端可创建/编辑/停用题库，可对题库内题目做增删改查与发布/下线
- [ ] 平台端可为课程配置多课时，课时类型覆盖视频/音频/文档/图文/考试；考试课时可配置题库、时长、题型题量、每题分值、及格分，总分自动汇总
- [ ] C端课程详情按序展示课时；未完成前置课时时后置课时不可开始
- [ ] 视频/音频课时进度达 100% 标记完成；文档/图文课时标记已读即完成
- [ ] 考试课时按规则从题库随机抽题（不含答案），判分后达到及格分即课时完成；不及格可重考
- [ ] 考试通过时记录试卷快照（题目+答案+得分）
- [ ] 全部课时完成（考试课时通过）时自动发放对应认证
- [ ] 已获认证的兼职抢标注任务不受影响；未认证兼职仍被拦截引导培训
- [ ] 双端构建通过，后端测试全绿

## 风险与开放问题

- 风险：课时删除/下线时已有学习记录的处置（保留记录、课时不可再学即可）
- 风险：题库停用或题目下线时，已配置的考试课时在抽题阶段应提示配置无效
- 待确认：重考是否限制次数（默认不限次）；多选计分是否严格全对（默认严格全对）
