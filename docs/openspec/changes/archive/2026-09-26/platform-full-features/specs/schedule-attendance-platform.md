## 排班管理 & 考勤管理（平台视角）

### Feature: 排班管理

**Scenario: 查看全平台班次列表**
```gherkin
Given 运营人员已登录平台
When 进入"职位运营 > 排班管理"页面
Then 显示班次列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 班次ID | 系统唯一ID |
  | 职位名称 | 所属职位 |
  | 企业名称 | 所属企业 |
  | 班次日期 | 工作日期 |
  | 工作时间 | 开始-结束时间 |
  | 工作地点 | 班次地点 |
  | 招聘人数 | 计划招聘 |
  | 已报名人数 | 当前报名 |
  | 已上岗人数 | 实际到岗 |
  | 状态 | 招聘中/已满员/进行中/已结束/已取消 |
  | 创建时间 | 班次创建时间 |
  | 操作 | 详情/取消班次 |
```

**Scenario: 按日期范围筛选班次**
```gherkin
Given 在排班管理页面
When 选择开始日期和结束日期并搜索
Then 列表只显示该日期范围内的班次
```

**Scenario: 按状态筛选**
```gherkin
Given 在排班管理页面
When 选择"进行中"状态并搜索
Then 列表只显示正在进行中的班次
```

**Scenario: 查看班次详情**
```gherkin
Given 在排班管理页面
When 点击某班次的"详情"按钮
Then 显示班次详情页，包含：
  • 基本信息：职位、企业、日期、时间、地点、招聘人数
  • 报名工人列表：已审核通过的工人名单
  • 考勤情况：已打卡人数、异常考勤数
  • 结算情况：已结算人数、结算总金额
```

**Scenario: 取消班次**
```gherkin
Given 某班次状态为"招聘中"或"已满员"且未开始
When 点击"取消班次"并确认
Then 该班次状态变为"已取消"，所有报名工人收到通知，名额释放
```

### Feature: 考勤管理

**Scenario: 查看全平台考勤记录**
```gherkin
Given 运营人员已登录平台
When 进入"职位运营 > 考勤管理"页面
Then 显示考勤列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 考勤ID | 系统唯一ID |
  | 工人姓名 | 打卡工人 |
  | 手机号 | 联系方式 |
  | 职位名称 | 所属职位 |
  | 企业名称 | 所属企业 |
  | 班次日期 | 工作日期 |
  | 签到时间 | 实际签到 |
  | 签退时间 | 实际签退 |
  | 工时 | 实际工时(小时) |
  | 状态 | 正常/迟到/早退/缺勤/异常 |
  | 是否补卡 | 是/否 |
  | 操作 | 详情/审核异常 |
```

**Scenario: 按考勤状态筛选**
```gherkin
Given 在考勤管理页面
When 选择"异常"状态并搜索
Then 列表只显示异常考勤记录
```

**Scenario: 按日期范围筛选**
```gherkin
Given 在考勤管理页面
When 选择日期范围并搜索
Then 列表只显示该时间段内的考勤记录
```

**Scenario: 查看考勤详情**
```gherkin
Given 在考勤管理页面
When 点击某条记录的"详情"按钮
Then 显示考勤详情弹窗，包含：
  • 工人信息：姓名、手机号
  • 班次信息：职位、企业、日期、计划时间
  • 打卡信息：签到时间、签退时间、签到地点、签退地点
  • 定位信息：签到经纬度、签退经纬度、距离偏差
  • 打卡照片：签到照片、签退照片（如有）
  • 异常信息：异常类型、异常描述
```

### Feature: 异常考勤审核

**Scenario: 审核异常考勤 - 确认正常**
```gherkin
Given 某考勤记录状态为"异常"
When 运营人员核实后点击"确认正常"并输入说明
Then 该考勤状态变为"正常"，记录审核人和审核时间
```

**Scenario: 审核异常考勤 - 确认异常**
```gherkin
Given 某考勤记录状态为"异常"
When 运营人员核实后点击"确认异常"并输入处理意见
Then 该考勤状态保持"异常"，记录审核意见，通知工人和企业
```

**Scenario: 补卡申请审批**
```gherkin
Given 工人提交了补卡申请
When 运营人员查看补卡申请详情，点击"通过"或"拒绝"
Then 补卡申请状态更新，考勤记录相应调整，通知工人
```

### Feature: 批量操作

**Scenario: 批量审核异常考勤**
```gherkin
Given 在考勤管理页面，筛选出"异常"状态记录
When 勾选多条异常记录并点击"批量确认正常"
Then 弹出确认对话框，确认后所选记录全部变为"正常"
```

**Scenario: 导出考勤记录**
```gherkin
Given 在考勤管理页面
When 点击"导出"按钮
Then 下载包含当前筛选条件的考勤Excel文件
```
