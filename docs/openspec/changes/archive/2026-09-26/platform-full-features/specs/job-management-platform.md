## 职位管理（平台视角）

### Feature: 职位列表

**Scenario: 查看职位列表**
```gherkin
Given 运营人员已登录平台
When 进入"职位运营 > 职位管理"页面
Then 显示职位列表表格，包含：
  | 字段 | 说明 |
  |------|------|
  | 职位ID | 系统唯一ID |
  | 职位名称 | 职位标题 |
  | 企业名称 | 发布企业 |
  | 分类 | 职位分类 |
  | 招聘人数 | 总招聘人数 |
  | 已报名人数 | 当前报名人数 |
  | 状态 | 招聘中/已招满/已下架/已结束 |
  | 是否置顶 | 是/否 |
  | 是否推荐 | 是/否 |
  | 发布时间 | 创建时间 |
  | 操作 | 详情/编辑/下架/置顶/推荐 |
```

**Scenario: 筛选职位**
```gherkin
Given 在职位管理页面
When 选择"状态"筛选条件并点击搜索
Then 列表只显示符合条件的职位
```

**Scenario: 按企业/分类筛选**
```gherkin
Given 在职位管理页面
When 选择"企业名称"或"职位分类"并点击搜索
Then 列表只显示符合条件的职位
```

**Scenario: 按关键词搜索**
```gherkin
Given 在职位管理页面
When 在搜索框输入关键词并点击搜索
Then 列表只显示职位名称/企业名称包含关键词的职位
```

### Feature: 批量操作

**Scenario: 批量下架职位**
```gherkin
Given 在职位管理页面
When 勾选多个"招聘中"的职位并点击"批量下架"
Then 弹出确认对话框，确认后所选职位状态变为"已下架"
```

**Scenario: 批量置顶**
```gherkin
Given 在职位管理页面
When 勾选多个职位并点击"批量置顶"
Then 弹出确认对话框，确认后所选职位变为置顶状态
```

**Scenario: 批量取消置顶**
```gherkin
Given 在职位管理页面
When 勾选多个已置顶职位并点击"取消置顶"
Then 弹出确认对话框，确认后所选职位取消置顶
```

**Scenario: 导出职位数据**
```gherkin
Given 在职位管理页面
When 点击"导出"按钮
Then 下载包含当前筛选条件的职位Excel文件
```

### Feature: 职位详情

**Scenario: 查看职位基本信息**
```gherkin
Given 在职位管理页面
When 点击某职位的"详情"按钮
Then 显示职位详情页，包含：
  • 基本信息：职位名称、企业名称、分类、标签、薪资范围
  • 招聘信息：招聘人数、已报名人数、工作地点、详细地址
  • 时间信息：发布时间、截止时间、工作时间描述
```

**Scenario: 查看职位报名记录**
```gherkin
Given 在职位详情页
When 点击"报名记录"Tab
Then 显示该职位的所有报名工人列表
  包含：工人姓名、手机号、报名时间、审核状态、操作
```

**Scenario: 查看职位排班记录**
```gherkin
Given 在职位详情页
When 点击"排班记录"Tab
Then 显示该职位的所有班次列表
  包含：班次日期、开始时间、结束时间、招聘人数、已报名人数、状态
```

**Scenario: 查看职位考勤记录**
```gherkin
Given 在职位详情页
When 点击"考勤记录"Tab
Then 显示该职位的所有打卡记录
  包含：工人姓名、班次日期、签到时间、签退时间、工时、状态
```

**Scenario: 查看职位结算记录**
```gherkin
Given 在职位详情页
When 点击"结算记录"Tab
Then 显示该职位的所有结算单
  包含：结算单号、工人姓名、结算日期、结算金额、服务费、状态
```

### Feature: 职位操作

**Scenario: 下架职位**
```gherkin
Given 在职位详情页或列表页
When 点击"下架"按钮并确认
Then 该职位状态变为"已下架"，前端不再展示
```

**Scenario: 重新上架职位**
```gherkin
Given 某职位状态为"已下架"
When 在详情页点击"重新上架"并确认
Then 该职位状态恢复为"招聘中"
```

**Scenario: 设置/取消置顶**
```gherkin
Given 在职位详情页
When 点击"置顶"/"取消置顶"并确认
Then 该职位的置顶状态相应变更
```

**Scenario: 设置/取消推荐**
```gherkin
Given 在职位详情页
When 点击"推荐"/"取消推荐"并确认
Then 该职位的推荐状态相应变更
```

**Scenario: 编辑职位信息**
```gherkin
Given 在职位详情页
When 点击"编辑"按钮修改职位信息并保存
Then 职位信息更新，记录操作日志
```

### Feature: 敏感内容检测

**Scenario: 自动检测敏感内容**
```gherkin
When 企业发布或编辑职位
Then 系统自动检测职位名称、描述、要求等字段是否包含敏感内容
  如果包含敏感内容，标记为"待审核"状态并通知运营人员
```

**Scenario: 人工审核敏感职位**
```gherkin
Given 有状态为"待审核"的职位
When 运营人员查看该职位并确认内容合规
Then 职位状态恢复为"招聘中"
```

**Scenario: 驳回违规职位**
```gherkin
Given 有状态为"待审核"的职位
When 运营人员确认内容违规并点击"驳回"
Then 职位状态变为"已下架"，记录违规原因，通知企业
```
