### 数据权限设计

| 角色 | 权限范围 |
|---|---|
| 超级管理员 | 全部模块 + 全部操作 |
| 运营主管 | 职位/报名/排班/考勤/结算 + 报表/活动 + 审核权限 |
| 运营专员 | 职位/报名/排班/考勤/结算（查看+简单操作） |
| 财务专员 | 交易流水 + 充值 + 对账 + 提现审核 |
| 风控专员 | 投诉工单 + 风控中心 + 评价管理 |
| 客服专员 | 客服中心 + FAQ + 工单处理 |
