## 新增需求

### 需求：兼职拥有包含基本信息的个人资料
系统须维护兼职的个人资料，包含姓名、手机号、头像、技能和可工作时间的偏好。

#### 场景：完善个人资料
- **当** 兼职注册后填写个人资料信息
- **则** 系统须保存资料并对企业可见

### 需求：兼职可上传简历
系统须允许兼职上传和管理简历。

#### 场景：上传简历
- **当** 兼职上传一份简历文件
- **则** 系统须存储简历并关联到该兼职资料

### 需求：企业可查看兼职资料和历史记录
系统须允许企业用户查看兼职的个人资料、在本企业的历史工作记录和评价。

#### 场景：查看兼职资料
- **当** 企业用户点击某位兼职的姓名
- **则** 系统须展示该兼职的资料、在本企业的工作记录和评分

### 需求：企业可评价兼职
系统须允许企业用户在岗位结束后对兼职进行评分和评价。

#### 场景：岗位结束后评价兼职
- **当** 企业用户在岗位结束后为兼职提交评分和评价
- **则** 系统须更新该兼职的综合评分

### 需求：企业可将兼职加入黑名单
系统须允许企业用户将兼职加入企业级别的黑名单。

#### 场景：拉黑兼职
- **当** 企业用户将兼职加入黑名单
- **则** 系统须阻止该兼职报名该企业的后续岗位

### 需求：兼职可查看个人工作历史
系统须允许兼职查看已完成的岗位记录，含日期、收入和企业评价。

#### 场景：查看工作历史
- **当** 兼职打开工作历史页面
- **则** 系统须展示已完成岗位的收入和收到的评价
