## Why

当前 C 端工人小程序的找活和打卡两大核心流程交互偏基础，信息层级不够清晰，操作路径偏长，影响工人的使用效率和报名转化率。具体问题包括：

1. **找活列表信息密度低**：卡片内容扁平，薪资/距离/时间等关键决策信息不够突出，工人刷列表效率不高
2. **报名流程多一步**：从详情页到确认报名需要跳转新页面，打断浏览节奏，增加跳出率
3. **打卡页不够直观**：以列表形式呈现，打卡按钮不够突出，工人不容易一眼找到"现在该做什么"
4. **视觉风格偏基础**：缺乏品牌感和活力感，与年轻打零工群体的审美有差距

本次升级围绕"快手抢单"理念，优化找活和打卡两大核心路径的视觉与交互，提升报名转化率和打卡操作效率。

## What Changes

### 找活流程优化
- **找活列表页升级**：渐变头部 + 问候语 + 搜索框，职位卡片加高层、信息重组，薪资数字放大、增加企业信息和报名热度
- **职位详情页优化**：班次选择前置到第一卡片，增加日期快速筛选，底部固定操作栏
- **报名流程简化**：去掉独立的确认报名页，改为底部弹窗确认，减少一步页面跳转
- **报名成功反馈升级**：全屏成功动效 + 引导去我的排班

### 打卡流程优化
- **打卡页仪表盘化**：上半部分大圆形打卡按钮 + 当前班次信息，下半部分今日班次列表
- **大按钮一键打卡**：超大圆形打卡按钮为视觉中心，带呼吸动效，不同状态不同颜色
- **状态一目了然**：位置/网络/提前打卡等状态实时显示，异常情况提前预警
- **打卡成功反馈**：全屏成功动效 + 签到时间 + 工时计时

### 视觉系统升级
- 沿用现有主色 `#10b981`（翡翠绿），统一色彩系统
- 统一圆角、间距、字体层级规范
- 年轻活力风格：渐变、动效、卡片阴影

## Capabilities

### Modified Capabilities
- `worker-job-discovery`: 工人端找活浏览和搜索体验升级，卡片信息重组，报名路径缩短
- `worker-attendance`: 工人端打卡交互升级，仪表盘式布局，大按钮一键操作
- `worker-ui`: 工人端整体视觉系统升级，统一色彩、间距、圆角、字体规范

## Impact

- **前端（worker-uniapp）**：影响 4 个主要页面（jobList、jobDetail、index 打卡页、clockIn 记录页），新增 2 个通用组件（报名确认弹窗、成功弹层）
- **后端**：无影响，所有功能复用现有接口
- **数据库**：无影响
- **小程序兼容**：全部使用 uni.*  API 和 rpx 单位，兼容微信小程序和 H5
- **不引入新依赖**：动画全部使用 CSS 实现，不增加第三方库

## Out of Scope

- 后端接口改动（复用现有接口）
- 企业端和平台端改动
- 新增业务功能（如智能推荐、筛选条件扩充等）
- 我的页面、消息页、收入页等非核心页面优化
