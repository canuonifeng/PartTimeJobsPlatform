## 新增需求

### 需求：运营人员可审核企业注册
系统须允许平台运营人员审核企业注册申请，批准或拒绝。

#### 场景：通过企业注册审核
- **当** 运营人员审核企业注册后点击"通过"
- **则** 系统须激活企业账号并通知企业管理员

#### 场景：拒绝企业注册
- **当** 运营人员审核企业注册后点击"拒绝"并填写原因
- **则** 系统须将企业状态设为"已拒绝"并通知企业管理员

### 需求：运营人员可审核被举报的岗位
系统须允许平台运营人员审核因违规被举报的岗位。

#### 场景：下架违规岗位
- **当** 运营人员审核被举报岗位后点击"下架"
- **则** 系统须下架该岗位并通知企业

#### 场景：驳回举报
- **当** 运营人员审核后认定岗位合规
- **则** 系统须驳回举报并保持岗位正常发布

### 需求：运营人员可查看数据看板
系统须提供全平台数据看板，展示活跃企业数、在招岗位数、注册兼职数、完成排班数和交易金额等核心指标。

#### 场景：查看平台数据看板
- **当** 运营人员打开数据看板页面
- **则** 系统须展示汇总指标及趋势图

### 需求：运营人员可管理系统配置
系统须允许运营人员配置系统级设置，包括岗位分类、平台费率、通知模板。

#### 场景：更新岗位分类
- **当** 运营人员新增、编辑或删除岗位分类
- **则** 系统须全平台同步更新分类列表

#### 场景：配置平台费率
- **当** 运营人员设置平台佣金比例
- **则** 系统须将该比例应用到所有相关交易
