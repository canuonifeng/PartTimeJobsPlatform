# 零工平台系统文档

## 概述

零工平台是一个完整的零工就业一体化平台，连接企业需求与零工人员，实现零工招聘、报名、排班、考勤、薪资结算和提现等全流程闭环。

### 核心业务流程

1. **企业发布职位**：企业发布兼职/全职工作岗位
2. **工人报名**：零工人员发现并报名职位
3. **企业审核**：企业审核报名并排班
4. **排班管理**：安排工作时间和地点
5. **打卡考勤**：记录出勤时长，计算薪资
6. **薪资结算**：企业确认并结算薪资
7. **工人提现**：零工人员提取结算款项

### 系统架构

零工平台采用三端架构设计：

- **企业端后台 (enterprise-service)**：端口 8081
- **工人端后台 (c-service)**：端口 8082  
- **平台端后台 (platform-service)**：端口 8083

#### 每个服务包含

- **控制器 (Controller)**：API接口层
- **服务层 (Service)**：业务逻辑实现
- **Mapper接口 (Mapper)**：数据库访问接口
- **Mapper XML**：SQL语句定义
- **实体类 (Entity)**：数据库表映射
- **VO类 (Value Object)**：响应数据结构
- **Command类 (Command)**：请求参数对象
- **过滤器 (Filter)**：安全认证

#### 前后端关系

- **企业小程序**：UniApp前端，连接 enterprise-service
- **企业 PC**：Vue 3 + Element Plus前端，连接 enterprise-service
- **工人小程序**：UniApp前端，连接 c-service
- **平台 PC**：Vue 3 + Element Plus前端，连接 platform-service

### 技术栈

#### 后端技术

- **语言**：Java 17

- **安全**：Spring Security
- **数据库**：MySQL (UTF8MB4)
- **ORM**：MyBatis
- **JWT认证**：JWT

#### 前端技术

### API规范

#### 请求/响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {...}
}
```

#### 认证

所有需要认证的接口都通过 `Authorization: Bearer <token>` 头携带JWT令牌。

### 错误码规范

- **200**：成功
- **400**：请求参数错误
- **401**：未认证/认证失效
- **403**：无权限
- **404**：资源不存在
- **500**：服务器内部错误
