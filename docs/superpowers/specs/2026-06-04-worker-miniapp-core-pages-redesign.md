# 工人端微信小程序 核心闭环 4 页视觉改造设计

## 背景

已完成 4 个 Tab 首页、找活、消息、我的视觉改造。继续改造剩余核心闭环页面：岗位详情、新增报名确认、排班、打卡记录。目标让这些页面的视觉风格与已改造 Tab 保持一致。

## 范围

改造：

- `worker-uniapp/src/pages/jobs/jobDetail.vue` — 岗位详情
- `worker-uniapp/src/pages/schedule/schedule.vue` — 我的排班
- `worker-uniapp/src/pages/attendance/clockIn.vue` — 打卡记录

新增：

- `worker-uniapp/src/pages/jobs/applyConfirm.vue` — 报名确认
- `worker-uniapp/src/pages.json` — 注册确认页路由

不改造：登录、实名、银行卡、编辑资料、收入、提现。

## 页面设计

### 岗位详情

参考设计稿岗位详情页。

结构：

1. 顶部导航栏：返回、职位详情、分享
2. Banner 图 emoji 占位
3. 薪资卡片：岗位名、日结 badge、薪资、日均估计、发布日期和浏览数
4. 基本信息卡片：工作时间、地点导航、招聘人数、工期
5. 岗位职责卡片
6. 任职要求卡片
7. 企业信息卡片：企业名称、认证状态、查看主页
8. 底部固定操作栏：电话按钮、立即报名按钮

数据策略：

- 继续调用 `getJobDetail(id)`
- 接口失败时展示外卖配送员兜底详情
- 原排班 slot 选择逻辑保留，选中后传给确认页
- “立即报名”改为跳转确认页

### 报名确认（新增）

新增设计稿报名确认页。

结构：

1. 步骤条：选择岗位 → 确认信息 → 报名成功
2. 岗位摘要：名称、地点、薪资、结算方式
3. 工作日期选择（横向可选 slots）
4. 工作时段选择
5. 报名须知提示条
6. 联系人和电话
7. 底部按钮：取消、确认报名

数据策略：

- 接收 jobId 和预设 date 等参数
- 确认后调用 `applyJob(jobId, { scheduleIds })`
- 成功后跳转首页或排班页，提示"报名成功"
- 失败时 toast 提示

路由注册到 `pages.json`：`pages/jobs/applyConfirm`

### 我的排班

参考设计稿打卡记录页风格，改造现有周排班视图。

结构：

1. 顶部导航：返回、我的排班
2. 周切换和日期选择
3. 排班统计：出勤天数、工时、迟到次数、缺勤次数
4. 排班打卡卡片列表：岗位名、签到/签退时间、工时、正常/迟到 badge

数据策略：

- 继续调用 `getMyShifts`
- 保留周切换和日期选择
- 接口失败时展示兜底排班数据
- 保留补卡申请交互

### 打卡记录

作为今日打卡页面，与首页签到签退联动。

结构：

1. 日期 header
2. 排班卡片列表
3. 签到/签退按钮

数据策略：

- 继续调用 `getMyShifts` 今日数据
- 保留 `checkIn`、`checkOut` 接口
- 接口失败时展示兜底数据

## 数据兜底

- 详情兜底：外卖配送员详情（18元/单、仓前街道利尔达科技园）
- 确认页兜底：从详情传参，无需纯兜底
- 排班兜底：设计稿同款排班数据
- 打卡兜底：今日排班示例
