# 企业分享二维码设计文档

**目标：** 企业端职位详情和列表页支持一键分享职位，并生成可供 C 端扫码报名的二维码。

**方案：** 企业端继续使用微信小程序原生分享能力进行职位传播，分享卡片只承载企业端职位详情页；在职位详情页新增“生成招工二维码”入口，由企业端后端生成可扫码的小程序码，二维码内容固定指向 C 端职位详情页 `/pages/jobs/jobDetail?scene={jobId}`。C 端详情页兼容 `scene` 参数后，就能直接完成报名。这样企业端负责传播，C 端负责报名，避免跨小程序直接分享卡片的限制。

**范围：** 只做最省事的落地方案，不新增 H5，不改报名业务，不做海报。

---

## 设计

### 1. 企业端分享卡片
- 企业端职位列表页和职位详情页都支持微信原生分享。
- 分享标题使用职位标题，分享路径指向企业端职位详情页，带 `id` 参数。
- 分享卡片只负责把内容发出去，不承担跨端跳转。

### 2. 招工二维码
- 企业端职位详情页新增“生成招工二维码”按钮。
- 点击后调用企业端后端接口生成二维码图片或临时图片地址。
- 二维码内容指向 C 端小程序职位详情页 `/pages/jobs/jobDetail?scene={jobId}`。
- C 端扫码后直接进入该职位详情页，仍使用现有报名按钮。

### 3. C 端承接
- C 端职位详情页保持现有报名能力。
- 若通过二维码进入，直接显示职位信息并允许报名。
- 不新增新的报名接口或中间页。

## 数据流
1. 企业管理员在职位列表/详情页点击分享。
2. 微信生成企业端职位卡片，接收方打开企业端详情页。
3. 企业管理员在详情页点击“生成招工二维码”。
4. 后端生成指向 C 端同一职位的二维码图片，扫码后带 `scene` 进入详情页。
5. C 端用户扫码进入详情页并报名。

## 错误处理
- 若当前页没有职位 ID，分享和生成二维码按钮不显示。
- 若二维码生成失败，提示“生成失败，请重试”。
- 若 C 端打开后职位不存在，展示现有的加载失败或暂无数据状态。

## 验证
- 企业端列表页可正常触发分享面板。
- 企业端详情页可正常生成二维码。
- 扫码后能进入 C 端对应职位详情页。
- C 端报名流程不受影响。
