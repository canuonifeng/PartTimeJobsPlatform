# 企业小程序零工信息展示与薪资接口修复设计

## 背景

企业小程序的报名管理、排班考勤页面需要在卡片中直接展示零工基本信息，避免企业审核和排班时还要进入详情或通过其他页面查找。薪资管理页面当前存在进入页面后未发起 API 请求的问题，需要修复加载链路。

## 目标

1. 报名管理卡片展示零工姓名、手机号、性别、年龄。
2. 排班考勤卡片展示零工姓名、手机号、性别、年龄。
3. 薪资管理页面进入后必须请求 `/attendance/hours` 并正常渲染返回数据。
4. 页面排版采用已确认的 A 方案：基本信息置顶，岗位/时间等业务信息用信息块承载。

## 方案

### 后端接口字段

- `ScheduleApplicationVO` 增加 `workerGender` 字段；现有 `workerName`、`workerPhone`、`workerAge` 继续保留。
- `ScheduleShiftVO` 增加 `workerPhone`、`workerGender` 字段；现有 `workerName`、`workerAge` 继续保留。
- 批量加载 worker 信息，避免循环查询数据库。
- 性别字段如果源数据为空，前端展示为 `未知`。

### 前端展示

报名管理：
- 卡片头部显示头像、姓名、`性别 · 年龄 · 手机号`、审核状态。
- 信息块展示报名岗位、排班时间、申请时间。
- 待审核时显示通过/拒绝按钮。

排班考勤：
- 卡片头部显示头像、姓名、`性别 · 年龄 · 手机号`、排班状态。
- 信息块展示岗位、日期、工作时间。
- 非取消状态显示取消排班按钮。

薪资管理：
- 修复页面初始化请求，确保进入页面调用 `listAttendance()`。
- 保持接口为 `GET /attendance/hours`。
- 若接口失败，显示加载失败提示；若为空，显示暂无考勤记录。

## 验证

- `enterprise-service` 执行 `mvn test`。
- `enterprise-uniapp` 执行 `npm run build:mp-weixin`。
- 手动验证报名管理、排班考勤展示姓名/手机号/性别/年龄。
- 手动验证薪资管理进入页面会发起 `/attendance/hours` 请求。
