2.2 **注册方式**：您可以通过微信一键登录或手机号验证码登录方式注册并使用本平台。注册成功后，您将获得本平台账户。

## 三、平台服务

3.1 **服务内容**：本平台为零工用工提供信息匹配服务，包括但不限于岗位浏览、报名应聘、排班管理、打卡考勤、收入查询、提现等功能。

3.2 **服务对象**：
- **工人端**：为求职者提供零工岗位信息、在线报名、考勤打卡、收入管理等服务。
- **企业端**：为企业提供岗位发布、报名审核、排班管理、考勤管理、结算管理等服务。

3.3 **服务变更**：我们有权随时对本平台的服务内容进行变更、暂停或终止，恕不另行通知。

3.4 **服务费用**：本平台目前为免费使用。如未来推出付费服务，我们将提前通知您并征得您的同意。

5.3 您确认报名的岗位均为您自愿选择，您应自行评估岗位的风险和适合度。

## 六、考勤与薪资

6.1 **打卡考勤**：您应按照排班要求在指定时间和地点进行打卡考勤。打卡数据将作为薪资结算的依据。

6.2 **GPS定位**：为验证打卡位置真实性，打卡时系统将获取您的地理位置信息。您在打卡时需授权位置权限。

6.3 **薪资结算**：您的薪资按照与企业约定的标准和方式计算。具体薪资以企业确认的结算金额为准。

6.4 **收入提现**：您可将平台收入提现至微信零钱或绑定的银行卡。提现申请提交后，我们将在1-3个工作日内处理。

6.5 **税务合规**：您理解并同意，您的收入可能涉及个人所得税申报义务，您应自行了解并遵守相关税务规定。
