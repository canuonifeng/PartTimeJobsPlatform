# 家政实施计划2

## 背景

基于零工平台「零工e站」现有能力，家政业务作为垂直场景独立规划，分为三个阶段逐步落地。

---

## Phase 1: 结算业务接入

**主要目标：将家政业务的结算流程纳入平台现有结算体系，实现线上化资金管理。**

### 1.1 接入范围

| 业务类型 | 说明 | 优先级 |
|---------|------|--------|
| 家政服务费结算 | 雇主→平台→家政人员，线上结算 | P0 |
| 家政人员提现 | 复用现有工人提现流程 | P0 |
| 平台服务费 | 按结算金额收取固定比例 | P1 |
| 保险代扣 | 家政人员按日投保，保费自动扣除 | P1 |

### 1.2 系统改动

| 模块 | 改动内容 |
|------|---------|
| balance_transactions | 增加 `biz_type=housekeeping` 业务类型枚举 |
| withdrawal | 复用现有提现接口，家政人员直接提现 |
| settlement | 结算单增加家政业务来源标记 |
| 运营后台结算管理 | 增加家政业务筛选维度 |

### 1.3 成功标准

- 家政人员完成实名认证并绑定银行卡
- 家政结算单可正常生成、审核、打款
- 家政人员提现到账成功
- 平台服务费正常收取

---

## Phase 2: 实训线上平台

**主要目标：建设家政实训全流程线上平台，覆盖报名、分班、订房、签到、评价。**

### 2.1 业务流程

```
学员报名 → 分班 → 订房 → 签到 → 培训 → 评价
   │        │      │      │      │      │
   ▼        ▼      ▼      ▼      ▼      ▼
 线上报名  系统分班  宿舍分配  每日签到  实训任务  双向评价
```

### 2.2 模块说明

#### 2.2.1 报名管理

| 功能 | 描述 |
|------|------|
| 课程/实训项目发布 | 管理员发布家政实训班次（工种/时间/名额/费用） |
| 学员线上报名 | 家政人员在线选择班次并报名 |
| 报名审核 | 管理员审核资质（身份证/健康证/技能证书） |
| 报名费支付 | 支持线上支付报名费/定金 |

#### 2.2.2 分班管理

| 功能 | 描述 |
|------|------|
| 自动分班 | 按技能水平/工种/时间自动分配班级 |
| 手动调班 | 管理员手动调整学员班级 |
| 班级管理 | 创建/编辑/关闭班级，配置班主任 |
| 学员名单 | 班级成员列表，支持导出 |

#### 2.2.3 订房管理

| 功能 | 描述 |
|------|------|
| 宿舍/房间管理 | 宿舍楼栋/楼层/房间/床位管理 |
| 在线订房 | 学员报名后在线选择宿舍和床位 |
| 入住登记 | 管理员确认入住、登记入住时间 |
| 退房管理 | 培训结束退房，释放床位资源 |

#### 2.2.4 签到管理

| 功能 | 描述 |
|------|------|
| 每日签到 | 学员每日定位签到（复用现有打卡能力） |
| 签到统计 | 按班级/个人统计出勤率 |
| 异常处理 | 迟到/早退/缺勤标记 |

#### 2.2.5 评价体系

| 功能 | 描述 |
|------|------|
| 学员评价 | 对课程/讲师/宿舍/食堂进行评价 |
| 讲师评价 | 讲师对学员表现进行评价 |
| 综合评分 | 学员实训综合得分（出勤+实操+考试） |
| 证书发放 | 培训合格后发放电子证书 |

### 2.3 成功标准

- 实训报名→分班→订房→签到→评价全链路走通
- 支持 ≥ 3 个家政工种实训课程
- 单期实训班容纳 ≥ 50 人
- 签到率 ≥ 90%

## Phase 3: 家政本地化零工促和平台

**主要目标：构架家政本地化零工促和平台，连接雇主与家政人员，实现供需匹配、交易闭环。**

### 3.1 平台定位

家政本地化零工促和平台 = 家政服务撮合 + 交易保障 + 信用体系

### 3.2 核心功能

#### 3.2.1 供需匹配

| 功能 | 描述 |
|------|------|
| 雇主发单 | 雇主发布家政需求（保洁/月嫂/育儿/养老/家电清洗等） |
| 家政人员接单 | 附近家政人员按技能/距离/价格筛选接单 |
| 智能推荐 | 基于位置/技能/评价的智能匹配推荐 |
| 即时沟通 | 雇主与家政人员在线沟通（复用消息服务） |

#### 3.2.2 交易闭环

| 功能 | 描述 |
|------|------|
| 线上下单 | 雇主选定家政人员后线上下单 |
| 在线支付 | 支持微信/支付宝在线支付（平台担保交易） |
| 服务确认 | 服务完成后雇主确认，资金解冻打款 |
| 售后保障 | 投诉/退款/纠纷处理机制 |

#### 3.2.3 信用体系

| 功能 | 描述 |
|------|------|
| 家政人员信用分 | 接单完成率/评价/违规扣分 |
| 雇主信用分 | 下单取消率/恶意差评/投诉记录 |
| 黑白名单 | 异常用户标记与限制接单/下单 |

#### 3.2.4 本地化运营

| 功能 | 描述 |
|------|------|
| LBS 展示 | 按地理位置展示附近家政人员/雇主需求 |
| 区域定价 | 不同城市/区域差异化定价 |
| 本地化活动 | 区域优惠券/新用户补贴/节日活动 |

### 3.3 技术架构

在当前微服务架构基础上，家政垂直场景独立部署：

```
┌──────────────────────────────────────────┐
│            家政服务网关                     │
│     housekeeping-gateway:8084             │
└────────────────┬─────────────────────────┘
                 │
    ┌────────────┼────────────┬────────────┐
    ▼            ▼            ▼            ▼
┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
│ 家政订单  │ │ 家政匹配  │ │ 实训管理  │ │ 评价信用  │
│ 服务    │ │ 服务    │ │ 服务    │ │ 服务    │
└───┬────┘ └───┬────┘ └───┬────┘ └───┬────┘
    │          │          │          │
    └──────────┴────┬─────┴──────────┘
                    │
          ┌─────────┴─────────┐
          │    MySQL + Redis    │
          └───────────────────┘
```

### 3.4 成功标准

- 家政撮合平台上线，覆盖 ≥ 5 个家政工种
- 日活雇主 ≥ 50 家，日活家政人员 ≥ 200 人
- 日均订单 ≥ 100 单
- 纠纷率 < 1%

---

## 总结

| 阶段 | 核心目标 | 预计周期 |
|------|---------|---------|
| Phase 1 | 家政结算接入，打通资金流 | 短期 |
| Phase 2 | 实训线上化，建设培训闭环 | 中期 |
| Phase 3 | 本地化撮合，构建交易生态 | 长期 |

三个阶段递进实施：先跑通结算和资金流，再建设实训培训体系，最终构建本地化家政零工撮合平台。
