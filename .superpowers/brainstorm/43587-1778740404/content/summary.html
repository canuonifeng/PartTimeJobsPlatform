企业端 — 设计总结

技术栈

Spring Boot MySQL MyBatis Redis RocketMQ XXL-Job Vue 3 + Element Plus UniApp (小程序)

架构

模块化单体，6 个领域模块 + 共享内核

📋岗位模块 📅排班模块 💰结算模块 👥人员模块 🏢企业模块 🔗共享内核

岗位发布核心实体

Job → JobRate(1:N) → JobSchedule(0:N) → JobApplication(N:N)

混合薪资：一个岗位支持时薪/日薪/计件三种模式同时配置

工作流

草稿 → 填写信息 → 配置薪资/排班 → 发布（直上）
企业内角色：管理员 | HR | 主管 | 财务
