## 新增需求

### 需求：企业可以创建和管理岗位
系统须允许企业用户创建岗位，填写标题、描述、位置、分类、人数、报名截止日期，以及可选的排班配置。

#### 场景：创建新岗位草稿
- **当** 企业用户填写岗位创建表单并保存为草稿
- **则** 系统须创建状态为"草稿"的岗位

#### 场景：发布岗位
- **当** 企业用户在草稿或已完成岗位点击"发布"
- **则** 系统须将岗位状态设为"已发布"并对兼职可见

#### 场景：关闭岗位
- **当** 企业用户关闭一个已发布的岗位
- **则** 系统须将岗位状态设为"已关闭"并停止接受新报名

#### 场景：岗位自动过期
- **当** 已发布岗位的截止日期已过
- **则** 系统须自动将岗位状态设为"已过期"

#### 场景：重新开放已关闭岗位
- **当** 企业用户重新开放一个已关闭的岗位
- **则** 系统须将岗位状态恢复为"已发布"

### 需求：岗位支持混合薪资规则
系统须允许一个岗位配置多种薪资规则：时薪、日薪和/或计件薪资。

#### 场景：为同一岗位配置多种薪资
- **当** 企业用户创建或编辑岗位时同时添加时薪和计件薪资
- **则** 系统须保存所有薪资规则并在岗位详情页展示

### 需求：岗位支持可选的排班时段
系统须允许企业用户为排班型岗位定义时段（日期、开始时间、结束时间、人数上限）。

#### 场景：为岗位添加排班时段
- **当** 企业用户为岗位配置排班时段
- **则** 系统须将这些时段关联到岗位供兼职选择

### 需求：兼职可以浏览和搜索岗位
系统须允许兼职按关键词、分类、位置和薪资范围搜索和筛选已发布的岗位。

#### 场景：按关键词搜索岗位
- **当** 兼职在搜索栏输入关键词
- **则** 系统须按相关性返回匹配的已发布岗位

### 需求：兼职可以报名岗位
系统须允许兼职向已发布岗位提交报名申请。

#### 场景：报名岗位
- **当** 兼职在岗位详情页点击"报名"
- **则** 系统须创建状态为"待处理"的报名记录

#### 场景：报名人数已满
- **当** 岗位已录用人数达到人数上限
- **则** 系统须阻止新的报名

### 需求：企业管理岗位报名
系统须允许企业用户查看、录用或拒绝兼职的报名申请。

#### 场景：录用兼职
- **当** 企业用户在待处理报名上点击"录用"
- **则** 系统须将报名状态设为"已录用"并通知兼职

#### 场景：拒绝报名
- **当** 企业用户在待处理报名上点击"拒绝"
- **则** 系统须将报名状态设为"已拒绝"并通知兼职
